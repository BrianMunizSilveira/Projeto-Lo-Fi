# 🎵 O que é Lo-Fi?

<img src="https://i.imgur.com/W9ZSZq4.jpeg" alt="Lo-Fi Illustration" width="350" height="350"/>

## 📖 Sobre o Projeto

Este projeto é uma landing page educativa que mergulha no universo do Lo-Fi, explorando suas características únicas, história e influência na música moderna. Desenvolvido com HTML, CSS e JavaScript, o site oferece uma experiência imersiva com efeitos parallax e design responsivo.

### ✨ Características Principais

- Design moderno com efeitos parallax
- Seções informativas sobre a história e evolução do Lo-Fi
- Animações suaves e transições elegantes
- Layout totalmente responsivo
- Navegação intuitiva
- Efeitos visuais inspirados no estilo Lo-Fi

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (com variáveis CSS e flexbox)
- JavaScript
- Font Awesome Icons
- Parallax Effects

## 🛠️ Como Usar

### Localmente
1. Clone o repositório
   ```bash
   git clone https://github.com/seu-usuario/projeto-lo-fi.git
   ```
2. Navegue até o diretório do projeto
3. Abra o arquivo `index.html` em seu navegador

### Online
Acesse o deploy do projeto: [Lo-Fi Project](https://brianmunizsilveira.github.io/Projeto-Lo-Fi/)

## 📱 Responsividade

O site é totalmente responsivo e se adapta a diferentes tamanhos de tela:
- Desktop (1024px+)
- Tablet (768px - 1023px)
- Mobile (até 767px)
